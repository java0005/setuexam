# setuexam
SetuExam (सेतु-परीक्षा) is a unified clearinghouse for Indian entrance exams (JEE, BITSAT, NEET, etc.) built on One Profile. One KYC. Universal Auto-Registry. It features one-click multi-exam cart checkout, in-browser canvas document auto-resizing to fix file caps, date clash detection, and auto-registration queues for upcoming exam windows.
